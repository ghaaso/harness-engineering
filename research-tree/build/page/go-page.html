What the run covers now

  • Graphs and knowledge graphs, widest: a map first, then up to 4 parts (about 5 keys a part).
  • Learned encoders: a map, then up to 2 parts. Memory and caching: a map, then up to 2 parts.
  • The other four fields: as before, one part each.
  • Every method is tagged by the memory it needs: fits 12 GB, needs 24 GB, needs more. None is dropped.
  • Each key has one owner. A key that answers another field's question is listed for that field and not read twice. Keys over a field's bound go to the not-covered list with the cost to cover them (98 M tokens a part); the run does not add parts by itself.
  • Tests and baseline comparisons come later. The review comparison on planted mistakes is moved out of this run (it is kept under later/f1/). So the go has no exception to your rule 3: nothing runs with the network on except the downloads you approve.
  • The problem sheet is kept: every writer scores its leads against it, and the closing maps the leads per sink.

Checks

  • Added back: a helper that goes silent is found. At each timer wake the coordinator looks for a unit silent for 20 minutes. Cost about 2.4 to 4.6 M Fable tokens, 0.4 to 0.8 Fable points. The longest working silence measured in 262 helper transcripts was 10.9 minutes.
  • Added back: a unit restarts at most 6 times, counted in the gate. After that it is given up and the hand-back lists what was not covered.
  • Not added: stopping a replaced helper from writing on. It needs a hook that refuses a stopped helper's writes, and a test of the app to see that the hook gets what it needs. That test needs your word first. An app restart or a usage limit ends the old helpers anyway; the stop and the restarted helper's wait-first stay.

Your settings, and what each costs

  • Auto mode, in the session's mode picker (there is no separate settings switch). Routine steps go on without you; what no mode approves still asks.
  • Remote Control, only if you want to answer from your phone: this session's own switch, this session alone. Cost: while it is connected, the session's transcript (your messages, the replies, the tool activity) is kept on the provider's servers. Without it, any stop waits for you at the desk. Push to the phone is not shown for this app: you look.

  • Windows sleep, form 2 only: set not to sleep on mains power until the run ends (Windows Settings, System, Power), and set back afterwards. The app cannot set it.
