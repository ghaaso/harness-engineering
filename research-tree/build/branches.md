## Where the record is thin

1. **Q5, the start.** The record has no way to tell the owner that a start is due, except the status view and FX-W5 → FX-W4's
   `stuck` path (about 4.75 h, FW:54). It also does not record whether the PreToolUse hook (which creates `start.json`) runs before the app refuses
   a start on a turn the owner did not type. If the hook runs first, a refused start leaves `start.json`, the lease runs out, and a
   `crash` no-start fence is charged, capped at `H_nostart` = 2 (FF:448-449, RC:98). That is a charge without a fault.
2. **Q5, the stop.** J point 3's tool names are INFERRED (RC:59). By its own description, read 2026-11-19,
   `mcp__ccd_session_mgmt__stop_session` "interrupt[s] another ... session's in-flight turn", and "the session stays open and idle".
   FX-CGATE step 6(a) writes a done file only when success means the process is gone (FF:429), so that tool's success does not count.
   `mcp__ccd_session_mgmt__archive_session` "stops the session's process", but outside auto and bypass modes the app asks the owner to approve
   each call, and it refuses a session that is mid-turn or has live background work. F-P10a stays open for P3.1. A builder that names a stop tool records the choice as a departure.
3. **r57-0109's clause** (a start allowed "on the turn that follows one of its own sessions ending") has no source, by the record's
   own note, and BUILD-PLAN.md:49 repeats it as measured. It is not relied on here. If the pilot shows it holds, only the brief line in row 1 widens.
4. **LR-4 with FX-W7.** FW:367 says how a dead `watcher.lock` holder is broken under the run lock, but not an unreadable lock with no holder
   to judge. The builder keeps lib.mjs:1370-1374 and records any departure.
5. **Guesses that only the pilot fixes:** `alarm_ms`, `realert_runs`, the kind deadlines (B1's bound), the start lease (PROBE 5),
   and FX-W5's interval and cap.
6. **Not in any model:** L2, B2, E2, RL, FX-W3, FX-W7, and Q5a with starts gated by the owner's words. Rows 3, 5, 7, 11 and 9 rest on
   the checked variant only. Rows 13-15 rest on reasoning from the documents, with no model.
