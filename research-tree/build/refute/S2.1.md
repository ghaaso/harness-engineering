handover.mjs:278-283 now). The test instead deletes coord.json and runs `handover bind --dry-run`. Exit 2 is
then checkCe's `no-coordinator`, raised before anything else, and coord.json is put back before endturn. So
the test passes whatever handover does on an exit 2. Under C4, a coordinator that follows the N2 rule calls
`endturn --ce N` after the exit 2, and endturn meets checkCe with coord.json at N+1. The turn then ends
without endturn, which is the N2 gap again.

A test that catches it, with the means the file already has:
1. a `drain` line of this ce (`lib.runFlags`);
2. thresholds `NO_LIST` (status.test.mjs:1006) for the raise;
3. a real `handover raise`, not a dry run: exit 2 `proc-unavailable` with the tree unchanged;
4. then endturn acknowledges K, spends the arm, and reports the sources unknown (exit 2).

**Dead assertions (C5).** Both behaviour tests call `hasReason(j, ...)` with `j` the spawn result of
`endturn(ctx, k)`. That object has no `.reasons`, so every `!hasReason(...)` is true whatever endturn reports.
The `acked.json` checks still catch a refusal, so this is a small item. The fix is `hasReason(j.json, ...)`.
