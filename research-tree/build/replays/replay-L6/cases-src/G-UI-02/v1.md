# After captures

Full-page screenshots of every built screen and the states the existing tests reach, as each
synthetic role sees it, at 375 and 1280 pixels wide. 130 pages, 17.0 MB.
Each address and state is captured once, with the client of its natural role (a refused natural role
falls back to the doctor reviewer, listed under `fallbacks`), plus one first-screen-after-sign-in page
per role that is not already in the set as that role.

How they were made: `docs/tasks/ui-design/evidence/capture.py` builds synthetic worlds in a
throw-away database (`clinic_ui2cap`), signs in one person per role with the Django test client,
fetches each address, and loads the returned HTML into headless Chromium (Playwright) by request
interception with the real `app.css`. Commit ed7fdf85bbe7 on claude/epic-blackwell-8e1f51.

Command, from the repository root:

    uv run --locked python docs/tasks/ui-design/evidence/capture.py --out docs/tasks/ui-design/evidence/before

Files are `<id>--<width>.png`; `manifest.json` lists every page (id, role, viewer, registry
key, glossary id, address, state, title, regions, files), the pages each role landed on, the
fallbacks and refusals (`fallbacks`, `skipped`), and any build error.
