The first check before commit 6 failed one test: 1998 of 1999 passed, 6/7 steps. The failure was in S09's `reporting/tests/test_close_withholding.py::test_no_s09_money_surface_gives_a_touched_tills_close_amounts_away[doctor_reviewer]`. The test takes every whole number from each page as "shown" (`numbers()` in `reporting/tests/test_gate_round1.py`). That includes digit runs inside the random UUIDs of History links. It then asserts that no difference of two shown numbers equals a secret amount, so a random UUID can make it fail by chance; that run reported 77003. Run alone three times it passed each time, and it touches nothing this branch changed. The check was rerun before the commit. This is recorded as a follow-up for S09, not fixed here: the test should ignore numbers inside identifiers.
