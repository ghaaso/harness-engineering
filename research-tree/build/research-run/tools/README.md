# The run's four scripts (plain Node, no packages; each prints one line, the rest goes to `run/`)
- `node tools/tokens.mjs <unit|run> [--root <transcript folder>]` prints `<unit> <calls> calls <x> M tokens (<y> M fresh)`; table in `run/tokens-<unit>.txt`. Unit = first word after `<kind>: ` in a helper's description; the coordinator's own session is unit `coordinator`; `run` = all.
- `node tools/wait.mjs <unit> <seconds <= 150> <file>...` prints `<unit> done <k>/<n> [missing: a, b] | tokens <x> M of limit <y> M`; over 150 s it prints `REFUSED` (exit 2). Checks every 5 s; log in `run/wait-<unit>.log`.
- `node tools/shuffle.mjs f<n> <review> <review>` prints `f<n> shuffled: ...written; key sealed`; masks arm words, drops arm-naming headers and metadata lines, writes `fields/<n>-*/score-in/review-1.md` and `-2.md` in random order, key in `sealed/f<n>-arms.json`.
- `node tools/gate.mjs <unit> --all <pct> --fable <pct>` prints `START <unit>: <numbers>` or `HOLD <unit>: <why>: <numbers>` (exit 1 on HOLD); appended to `run/usage.log`. Holds on a null `preparation_M`, an unreadable config, or no reset ahead.
- Transcripts: the app's folder for the run root (`C--research-runs-2026-11-harness-leads`, and folders starting with that name plus `-`) under `~/.claude/projects/`. A helper's own helpers are in the same `<session>/subagents/` folder (flat, with `parentAgentId` and `spawnDepth` in the `.meta.json`), so they count under their own unit.
- Tests: `node --test tools/*.test.mjs` (fixtures in `tools/fixtures/`; they use a temporary run root via env `RUN_ROOT`, `CLAUDE_PROJECTS`, `GATE_NOW`, `WAIT_POLL_MS`).
- Not tested: a real run folder (none exists yet); the gate's reading of a fractional reset time zone is UTC only.
- `node tools/typed.mjs "<words>" --out <file>` prints `typed: <k> turns match "<words>" in <s> sessions -> <file>`; searches only the owner's typed turns (user records with `turnOrigin` "human"; older records without it: no isMeta, not a tool result, text not starting with "<") in top-level session transcripts of all project folders, locally; terms split on comma, semicolon or `|` (else one phrase); the file holds date, session, project and the matching sentence with one either side, newest first, at most 200.
- gate.mjs holds no lock: each START is a numbered slot `gate/<k>.json` made with the exclusive flag (k = 1 + highest read; on EEXIST it decides again, 12 tries, then `HOLD ... gate contended`); slots are the record of starts, a HOLD makes none, a slot left by a killed call needs no clearing.
- shuffle.mjs on a repeat for the same field reuses `sealed/f<n>-arms.json`'s order and never makes a new key.
- `node tools/commit.mjs "<message>" <path>...` git add + commit of only those paths in the run's repository; prints `committed <hash>: <k> path(s)`, `nothing to commit ...` or `FAILED: ...`. Waits up to 100 s while `.git/index.lock` exists; removes it only if older than 30 s (a commit measured 162-198 ms in a 300-file scratch repo) and no git process runs.
