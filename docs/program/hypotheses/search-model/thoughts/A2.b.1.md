# A2 option 1: joint reading with relation tokens
Lens: language model first.
**Mechanism.** One pretrained code-and-text encoder (cut-off no later than the test cut-off, D7) reads question and
candidate as one sequence; every layer attends across both. First segment, per question: task words, the issue title
and body; change, the first commit's diff with its files marked; error, the error text with each trace frame's file
marked. Second segment: the candidate's path and a chunk of its content at the asking time (each read jointly;
the candidate keeps its best chunk). Between them, one relation token per kind r of link between candidate and the
question's starting files: g_r = W_r phi(x_qc,r), x_qc,r the amounts A3 computes for that kind (decayed, size-weighted
count, age, hops), relative to the repository; W_r a mix of a few shared matrices (N 13.2). They enter as input
embeddings, the first place of N 12.7. Score:
s(q,c) = v^T h_CLS(q, c, g_1..g_R) + a^T x_qc.
The linear term carries exact amounts past the encoder.
**Needs from other parts.** A3: x_qc exact. A4: the kinds. A5: amounts dated before the asking time. A6: a retrieved
candidate set. A7: the loss. A9: the pair budget.
**Can.** M1 by construction: the candidate is described with the question in view at every layer, so two files with
the same surroundings, or one file under two questions, get different scores; this is the joint pair computation
that N 9.4 and N 9.8 leave open. M6 in part: content reaches a right file with no history, inside the retrieved set.
M2 by construction through a^T x_qc. M3 by construction: no identity, amounts relative. M5 in part: W_r per kind,
bounded by the shared basis.
**Cannot.** See a whole repository: one encoder pass per pair and chunk, so other ranks come from A6. See structure
beyond one link from the starting files unless A3 or A4 put it in x_qc. Count from text: language models "are NOT
trained to predict the future" and read digits badly (N 13.9), hence the linear path. Counterexample: a config file
sharing no word with the question and no link to the starting files scores as noise. Nearest veto W7: relation
tokens and x_qc carry the typed links. W6: attention spans one pair's tokens, not all files.
**Rests on.** N 9.4, N 9.8, N 12.6, N 12.7, N 13.2, N 13.9; D 6.4 (phi's scaler fitted on training repositories);
record: research-tree/build/improve/units/T3/report.md (change text names a right file in 37 % of tasks; text added
0.010 to the tree ranker); assumption: a change or issue describes the code it touches, so question and right file
share names; count first: per question kind, the share of right files with no history link whose content shares an
identifier with the question; tokens per question plus chunk.
**Refuted if.** On validation repositories, replacing h_CLS by a constant leaves the rank of right files with no
history link unchanged, or shuffling question segments across questions scores the same.
