# A6 option 1: language-model channels score all, joint shortlist
Lens: language model first: a large pretrained model of text and code does the main work, the graph enters around or inside it.

**Mechanism.** Two stages over all files alive at the asking time t.
1. *Every file scored.* s1(q,f) = u^T z(q,f), z relative to the repository, with channels:
   - dense: best and top-3 mean similarity of q to f's chunks. Chunk vectors frozen, stored once per content hash; only the question side carries adapters tuned on training repositories and times (D 6.2);
   - lexical: BM25 over path and content, idf from the files alive at t;
   - names: identifiers and paths in q, and those the decoder generates after reading q and the starting files, resolved against the symbol table at t (D5). An unresolved name is dropped: the model proposes, it cannot invent a file;
   - exact: the kernel bank to the starting files (A3.c.1) and typed path counts up to two hops (A4.c.1), zero with a flag where none.
2. *Shortlist read jointly.* C = top N by s1, plus files named in q or the trace and the top M by joint-change kernel. The joint reader of A2.b.1 scores C. Final order: C by joint score, then all other files by s1. Every file gets a rank.
Training: s1 against all files with negatives drawn at known probabilities (D 3.2), never a right file; the joint reader on shortlists from training repositories.

**Needs from other parts.** A1.b.1 (chunk vectors, symbol facts); A2.b.1 (joint reader); A3.c.1; A4.c.1; A5.b.1 (cut at t, the LM cut-off mark). A7: both losses. A9: index, N.

**Can.** M6 by construction: every file reached directly by content and names, no hop limit, no stacked steps (N 11.3); 30 to 66 % of right files had no joint change. M1 by construction inside C, in part outside. M2 by construction: the exact count is a channel at both stages. M3 by construction: no identities; a path is read as text. M7 open on a count of chunks per repository (cost linear in them).

**Cannot.** Find a right file sharing no word, name or path with the question or its starting files. Counterexample: a build setting a new feature also needs. Rescue a file s1 ranks below N. Escape the decoder's memory: a generated name may be recalled, not reasoned. Nearest veto W1: outside C the dense channel is two vectors, but s1 also reads pair-specific names and exact counts, and inside C the reading is joint. W6: attention spans one pair.

**Rests on.** N 9.4, N 9.8, N 11.3, N 12.1, N 12.5, N 13.9; D 3.2, D 6.2; record: FACTS-MODELS-SO-FAR.md (retrievers swing +23 and -14 against text search by repository; no joint change for 30, 66, 21 %); record: `research-tree/build/improve/units/U3/report.md`. count first: recall at N, per repository, of right files with no joint change and no two-hop path.

**Refuted if.** On validation repositories, removing the dense and generated-name channels leaves that recall within its interval; or the gain is larger on repositories created before the decoder's cut-off than after.
