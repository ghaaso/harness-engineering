# A4 option 1: exact typed path counts, ranker reads
Lens: exact relational computation first.
**Mechanism.** Question-to-file kinds Q = {in change, named in text, in trace}. File-to-file kinds R, each directed kind kept as two: import resolved, name matched but unresolved, use, test by import, test by name (out and in for each); folder sibling and joint change through an event node (symmetric). |R| = 12. With A_r the adjacency of kind r in the store cut at the asking time and S_q the start files, for each path type p = (k, r1) or (k, r1, r2), k in Q, and every candidate c:
- raw count x_p(c) = sum over s in S_q of kind k of (A_r1 A_r2)[s, c] (sums, so multiplicities pass; N 9.5);
- discounted count, each middle file m weighted 1/deg_r2(m), so a path through a 2,000-file folder is worth little;
- the number of distinct start files reaching c by p.
Joint-change edges carry A3's event weights, so the decayed, size-weighted joint count is path (k, joint) exactly. At most |Q|(|R| + |R|^2) = 468 path types; a type with no support in training repositories is dropped there. Amounts enter raw and relative to the repository's scale. A learned ranker reads the vector; a kind is a feature position, never a parameter per file.
**Needs from other parts.** A1: relative amounts. A3: event weights. A5: the store cut at the asking time. A6: a rank for files beyond two hops. A7/A8: the ranker and loss.
**Can.** Represent every pattern of N 13.8, because nothing is embedded: a kind and its reverse are different features (antisymmetry, inverse); folder and joint change are symmetric; two-step composition is a path type; one-to-many is many non-zero counts. M1 by construction (every feature is relative to S_q). M2, M3, M5 by construction. M4 given A5. M6 in part (two hops). M7 by construction: sparse products per question.
**Cannot.** See past two hops: a right file reached only as test -> import -> import scores zero everywhere. Tell which symbol a link carries: two candidates that use the start file, one through the function the diff edits, one through an unrelated constant, get identical counts (A2's work). Recover a conjunction lost by aggregating paths (D 9.2). Nearest veto: W5; not under it, because nothing is left to stacked learned steps and reach beyond two hops is handed to A6.
