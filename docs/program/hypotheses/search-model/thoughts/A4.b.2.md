# A4 option 2: relational passing with basis-shared weights
Lens: language model first. This option departs from it: the language model only encodes nodes (A1), and the kinds
are handled in algebra, because the material gives exact rules for direction and count there.

**Mechanism.** Each directed kind r gets a forward relation r and an inverse r^-1. Symmetric kinds get one relation.
The question node is marked (a root mark), so the computation is relative to q. One layer:
h_v' = W_0 h_v + sum_r sum_{u in N_r(v)} a_uv W_r h_u, with W_r = sum_b alpha_rb V_b (B shared basis matrices).
a_uv is the link's own weight (decayed amount from A3), and the sum is not divided by the degree. Aggregation runs in
two stages, inside each relation and then across relations. The score of c is a fixed readout of h_c after L layers
from the marked q.

**Needs from other parts.** A1: node vectors from the language model. A3: the link weights a_uv. A6: the subgraph or
candidate set. A5: links dated before the asking time.

**Can.** M5 by construction: direction is kept, since W_r differs from W_r^-1. Parameters are B·d^2 + R·B, so a new
kind costs B numbers. M2 by construction for one hop: an unnormalised sum keeps counts. M1 by construction through the
root mark: two candidates with the same surroundings differ by their place relative to q. N 13.8 patterns: asymmetry
and inverse hold (separate matrices), composition up to L links (layers chain linear maps), one-to-many (no entity
vectors). M3: only coefficients are learned.

**Cannot.** Give a kind never seen in training anything but alpha = 0. Counterexample: a new link kind added after
training is ignored, where option 1 would read its phrase. Treat neighbours of one kind differently unless a gate is
added (isotropic within the relation). Reach past L links (W5 is nearest; reach is A6's part, and L stays small). It
does not avoid the WL limit for nodes with the same subtree; the root mark lifts only position relative to q. Nearest
veto is W2: avoided, because the sum is unnormalised.

**Rests on.** N 13.2 (per-relation matrices, the basis remedy, direction), N 13.3 (two-stage aggregation), N 9.5
(sum, not mean), N 9.10 (root marking), N 13.8, record: `docs/program/hypotheses/search-model/FACTS-MODELS-SO-FAR.md`
(the mean-aggregated pair-head network did not exceed its own count features). Count first: links per kind per
repository, to see which kinds have enough examples to earn their own alpha.

**Refuted if.** Tying all alpha_r to one shared value (one relation) gives the same validation score. Or removing the
inverse relations changes nothing.
