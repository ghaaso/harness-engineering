# A6 option 2: content retrieval by token matching
Lens: graph first; this option departs from it. Following the material: past two hops the graph's value is unmeasured (FACTS: 8.5, 45, 11 points of right files within two hops), and walks favour hubs (D 2.8). So far files are reached by content alone; structure serves only near files.

**Mechanism.** Every file alive at asking time t is split into chunks. Each chunk's tokens are encoded once per content hash by an encoder E (cut-off before the test cut-off; tuned on training repositories and times only, D 6.2, D 6.4). For question q, each file v gets three content channels:
- late interaction: s_LI(q,v) = max over chunks d of v of sum over question tokens i of max over tokens j of d of <E(q)_i, E(d)_j>; each question token finds its own match;
- exact symbols: names, paths and routes in q that v defines or matches (D5 facts);
- BM25 over split identifiers, idf from files alive at t.
Near channels: A3's exact kernels and A4's two-hop path counts.
*Candidates.* C(Q) = union of each channel's top k_ch; each k_ch set on validation where that channel's recall stops rising.
*Every file ranked.* A small ranker f0 reads all channels as percentiles within the question; C is reordered by the joint scorer; the rest follow by f0.

**Needs from other parts.** A1.b.1 the encoder and chunks (or A1.a.1, untuned); A2.b.1 joint reader or A2.a.2 pair record inside C; A3.c.1 kernels; A4.c.1 path counts; A5.c.1 as-of view; A7 the retriever's contrastive loss, with negatives never right files (W9); A9 the token index.

**Can.** M6 by construction for files whose content shares meaning with q. Whether tuning removes the retrievers' swing by repository (FACTS: +23, -14 points against BM25) is open on held-out repositories. M1 for the tail in part: token-level matching makes the score depend on which part of q is answered. M3: nothing per file; idf and percentiles per repository. M4: index and idf cut at t. M7: index once per content hash.

**Cannot.** Reach a file through structure past two hops. Counterexample: the test of a module that imports a changed file. It shares no words with the diff; only a name match finds it. Find the unimported, never-changed cache config of option 1. Storage grows with tokens (count first). Tuning may fit the training vocabulary only. Nearest veto W1: each side is encoded apart. Not two pooled vectors; inside C the joint reader decides, and only the tail rank rests on it.

**Rests on.** N 9.4, N 9.8 (why the final score is joint), N 12.5, N 13.9; D 2.8, D 6.2, D 6.4; FACTS (retriever swing; reach of history and two hops); record: `research-tree/build/improve/units/U3/report.md`. count first: per repository, the share of right files at three hops or more with no content channel in their top k.

**Refuted if.** On held-out repositories, among right files with no history and no two-hop link, s_LI raises C's recall no more than BM25 plus symbols. Or option 1's walk channels add recall of such files beyond this option's.
