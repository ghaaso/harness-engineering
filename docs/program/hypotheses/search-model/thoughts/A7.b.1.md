# A7 option 1: corrected sampled softmax, cross-encoder logit
Lens: language model first.

**Mechanism.** Output per candidate: one logit, s(q,c) = v^T h_CLS(q,c,g) + a^T x_qc (A2.b.1). At asking time t: F_t is the files alive, P the right files alive (edited or deleted), A the added ones, R_u every right file of the same unit of work.
- *Negatives.* A fixed set D, A6's top k minus P. Then m draws from the rest of F_t minus P and R_u, with proposal pi(c|q) = lambda·softmax(r(q,c)/T) + (1-lambda)·uniform. Here r is A6's cheap score, so pi is known for every file.
- *Loss.* Each right file is ranked against wrong files only:
  Z^ = sum_{d in D} e^{s_d} + (1/m) sum_j e^{s_{n_j}}/pi(n_j), an unbiased estimate of the sum over all wrong files alive;
  L_q = (1/|P|) sum_{p in P} [log(e^{s_p} + Z^) - s_p].
- *New file.* Each folder alive is a slot, "a new file here", read by the same encoder (folder path, names in it, question). Its own list: L_q^new = -log softmax_slots(true folder), only where A is not empty.
- *Weights (D11).* w_q = min(1/|Q_R|, b), renormalised so that each repository sums to the same total. The step-by-step questions of one unit share that unit's weight. Bulk changes are read apart. b is set on validation.

**Needs from other parts.** A1.b.1 (tuned decoder, amounts on a bypass path); A2.b.1 (score form); A3.c.1 (exact x_qc); A4.b.1 (relation lines); A5.b.1 (cut-off mark). A6: a cheap score r over every file alive. A9: k + m + |P| tuned passes per question.

**Can.** Undo the over-drawing of hard files with the -log pi correction (D 2.9, D 3.2). In expectation this is the full softmax over every file alive; hard negatives cut variance, not the target. M7: by construction for the loss, the negatives and the weights; open for compute, on a count. M1 and M2: by construction, through A2.b.1. With several right files, none pushes another down. New files: in part, at folder level.

**Cannot.** Mean anything across questions: softmax is shift-invariant, so it cannot say how many files to read (option 3). At small m, log Z^ is biased low (Jensen). Score every file alive at test: the tail comes from A6, yet uniform draws spend training on it. Name a new file below its folder.
Nearest veto: W9, avoided because P and R_u are excluded. This is not the record's "historical negatives" (0.141 to 0.007). Those labelled real pairs of other times false, uncorrected. Here an earlier partner is a negative only when it is wrong for this question, weighted down by 1/pi.
