# A7 option 3: calibrated per-file probability, unbiased total
Lens: exact relational computation first; what can be computed exactly from the store relative to the question is computed, and a learned ranker reads it.

**Mechanism.** The output is a probability, not only an order: p(q,c) = σ(s(q,c)), with s = o(q) + b_k(q,c) + f_θ(x(q,c)). b_k and x are as in option 1. o(q) = logit(m_R / N_t) is an exact statistic of the repository before t: m_R is its mean number of files per unit, N_t the number of files alive. Candidates are option 1's U(q), new-file slots included.
- *Loss.* The Bernoulli log-likelihood over every candidate, estimated as a Horvitz-Thompson total:
  L(q) = -Σ_{p∈P} log p_p - Σ_{c∈S} (1/π_c) log(1 - p_c).
  S holds all of R(q) \ P(q) (π = 1) and a Poisson sample of the rest with known π_c > 0. L is linear in per-file terms, so its expectation is exactly the full loss over every file alive (D 3.2). No Jensen bias, unlike option 1.
- *Weights.* w_q = min(1/n_R, β), as option 1; no division by |P| inside a question, since every file is its own trial. Bulk-flagged questions weigh zero.
- *Use.* Σ_c p_c estimates how many files are right, so the tool can say how many to show and stop.

**Needs from other parts.** A1.c.1 and A2.a.2: x, amounts relative to the repository. A3.c.1, A4.c.1 and A5.c.1 (A5.c.3 optional): exact columns at the cut, which define R(q). A8: the family of f_θ. A10: calibration read per repository.

**Can.** M7 by construction: the loss is an unbiased estimate of the full total; negatives are never right files of q; weights and π are set by design. M2 and M1 by construction, through x and the offset. M3 by construction: o(q) is recomputed from data at every t, not learned per repository. M8 in part: o + b_k alone is the baseline turned into a probability.

**Cannot.**
- Aim at the order. Thousands of easy wrong files dominate the sum. Counterexample: shifting every score of a question by one constant changes L and leaves every rank unchanged.
- Represent right files that come together. A module and its test are scored as independent trials.
- Stay calibrated outside the range of scales seen in training. Nearest W10; not under it, because amounts and o are relative.
- Tell unlabelled right files from wrong ones; as option 1.

**Rests on.** D 3.2, N 13.6, D 6.2, D 6.4 (β and κ on training and validation repositories only), D 8.1, D12 (measures per file). Assumption: a stopping point is worth having, since the number of right files varies widely. Count first: the spread of |P| within and between repositories.

**Refuted if.** On validation repositories, option 1's scores turned into probabilities by one temperature fitted on validation are as well calibrated per decile as this option on unseen repositories. Or this option's per-repository ranks fall below option 1's beyond the intervals.
