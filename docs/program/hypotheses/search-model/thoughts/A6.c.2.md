# A6 option 2: learned descent through the folder tree
Lens: exact relational computation first. Departs from it: a region known from layout and content across repositories ("a schema question lands in migrations") has no exact path to the question, so the region is learned.

**Mechanism.** The folder tree at the asking time is the partition, so none has to be searched (N 12.4).
- *File token* x_c: a learned projection of c's exact columns (A3.c.1, A4.c.1, relative amounts) and its chunk vectors (A1.a.1).
- *Folder token* x_F = MLP(sum over children of MLP(x_child)) plus relative size and depth; a sum, so multiplicities pass (N 9.5).
- *Attention.* One transformer reads [question tokens; every folder token]. A folder pair's attention score gets a bias from the exact import and joint-change counts between the two folders (N 12.7).
- *Score for every file alive:* s(c) = sum over folders F on c's path of f(F | q) + g(x_c, h_F(c), q) + a^T x_qc, h_F(c) being c's folder after attention, a^T x_qc the exact columns on a linear path (as A2.b.1). A sum, not a hard cut: a wrong folder lowers a file, never removes it. A "new file here" entry per folder is scored by f.
Above a stated number of folders, attention runs one level up, then inside the chosen folders.

**Needs from other parts.** A1.a.1 (chunk vectors); A2.b.1 (joint reading of the top K, linear path); A3.c.1, A4.c.1 (exact columns, counts between folders); A5.c.1 (the cut view); A7 (loss over all files and "new file" entries); A9 (memory).

**Can.** M6 by construction: every file is a short route from the question through its folders, O(log_S n) hops, no chain of local steps (N 11.3). M1 by construction: the question is in the attention. M2 by construction: sums in tokens, exact columns on the linear path. M3: no identity. M7 open: count first the folders per repository.

**Cannot.** Find a right file in a large folder of unrelated files: the token is over-loaded (N 11.1), so the in-folder term must carry it. Help a flat repository: one folder, nothing over option 1. Promise transfer: attention learned over layout conventions that differ by ecosystem may not carry to an unseen repository (N 8.4). Nearest veto W6: attention is over folders, not all pairs of files. Not W5: one attention step over the tree.

**Rests on.** N 8.4, N 9.5, N 11.1, N 11.3, N 12.4, N 12.5, N 12.7; D 9.4; FACTS (8.5, 45, 11 points of right files within two hops). assumption: folders group files by purpose, so right files cluster by folder. count first: folders per repository; per repository, how many folders the right files of one question span.

**Refuted if.** On held-out repositories, among right files with no joint history and no two-hop path, adding f and h_F to option 1's columns moves no per-repository rank beyond the resampling intervals; or the gain shows on training repositories only.
