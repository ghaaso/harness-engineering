# A1 option 1: typed nodes with frozen-text features
Lens: graph first. The model computes on the typed neighbourhood handed over by the data, with the question as a node of it.

**Mechanism.** Every kind in D14 is a node kind or an edge kind, and each kind has its own trained input projection (N 13.3).
- Text, diff, error text and each file's content at t are cut into chunks. Each chunk is embedded by one frozen pretrained code-and-text encoder whose cut-off is no later than the test cut-off (D7). The chunk becomes a node with a `part-of` edge, and nothing is pooled before the model. Embedding is keyed by content hash (D3), so each chunk is computed once. The path is embedded as text. There is no file or repository identity (W3).
- An event node carries exactly 1/n_e (the files changed), its age a_e = t - time(e), and a fixed bank (1/n_e)·exp(-a_e/τ_k). A sum over event edges then gives the decayed, size-weighted joint count exactly.
- Each amount enters as log(1+x), as its quantile among the repository's own values before t, and as a missing flag. No fitted scaler, no leak (D 6.2).
- Links are typed and directed; each reverse is a kind of its own. Edge features: resolved or not, and the rule behind a test link.
- A repository node holds the description and the scale amounts, and is linked to the question only.
- Question-free structure features, on the import, use, test and folder graph at t: random-walk return probabilities for k = 1..K (N 10.4), and degree per kind as a quantile. Laplacian eigenvectors are not used (W11).

**Needs from other parts.** A2: the candidate made relative to the question. A3 and A4: sum aggregation per kind. A5: decay beyond the bank. A6: the candidates. A9: one embedding pass per content hash.

**Can.** By construction: M2 (the exact count is a sum of the inputs), M3 (no identities, the repository's own scale) and M4 at the input. In part: M5 (kinds and direction are given) and M6 (content is present; reach is A6's).

**Cannot.** A frozen encoder cannot learn a repository's private vocabulary: "billing" against `invoice_svc/`. Return probabilities cannot separate nodes with equal signatures (N 10.4), such as mirrored test folders. A unique description could be memorised in training. Nearest veto: W1, since a file's input ignores the question. It is not struck: A1 fixes inputs only, and A2 joins the question before any score.

**Rests on.** N 9.5, N 9.10, N 10.3, N 10.4, N 13.3, N 13.9; D 6.2, D 8.1, D 9.3, D 9.4. Record: `research-tree/build/improve/units/T3/report.md` (the one-over-size weight carries counting). Assumption: a frozen encoder holds no trace of the training repositories, so it transfers.

**Refuted if.** On unseen repositories, raw logs in place of quantiles match this arm in the extreme size strata. Or: removing the chunk nodes leaves hits unchanged on right files with no joint change and no code link.
