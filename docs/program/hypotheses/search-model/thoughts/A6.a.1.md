# A6 option 1: question-rooted walks plus content edges
Lens: graph first. The model computes on the typed neighbourhood, with the question as a node.

**Mechanism.** G_t: files alive at asking time t, events, folders, A4's typed links, cut at t (D 9.4). Question node Q links to starting files S_k(Q), and to every file v by content edges: b(q,v), BM25 over split identifiers, idf from files alive at t; m(q,v), best question-chunk cosine (A1 frozen encoder); y(q,v), names or paths in q that v defines or matches.
*Stage 0, every file, on a processor.* Random walks with restart from Q, one per relation group (history via events weighted n_e^-1 exp(-a_e/tau); code links; folder) and one on their union: pi = alpha e_Q + (1 - alpha) P^T pi, by K sparse products (N 2.3, N 14.4). They reach past two hops. Each pi also enters over degree, undoing the walk's bias (D 2.8, D 2.9). A3's exact counts and A4's path counts sit beside them; amounts are percentiles within the question. A small ranker f0 reads the channels.
*Candidates.* C(Q) = union of each channel's top k and f0's top K; K set on validation where recall stops rising.
*Stage 1.* A2.a.1's propagation on C, S, Q and their neighbourhood; each candidate keeps a direct edge Q->v carrying its channels and the joint reading phi(q, x_v), so a far file is one hop from Q (N 11.3).
*Every file ranked.* C by stage 1; the rest below, by f0 (D12).

**Needs from other parts.** A1.a.1 chunk vectors, relative amounts; A2.a.1 rooted propagation with Q->v edges; A3.c.1 exact kernels; A4.a.1 or A4.c.1 kinds and path counts; A5.c.1 as-of view; A7 the losses of f0 and stage 1; A9 walks once per question.

**Can.** M6 by construction for the route (content and structure in, a direct path per candidate); recall of C open on a count. M1 by construction (rooted at Q). M2: exact counts beside the normalised walk. M3: no identities, values relative. M4: graph and idf cut at t. M7: linear in edges times K.

**Cannot.** Find a right file sharing no word, symbol, history or path with Q. Counterexample: "pages load slowly", right file an unimported, never-changed cache config; only f0's question-free channels place it. Stage 1 cannot lift a file left out of C: C's recall caps everything. Nearest veto W1: m is two vectors computed apart, but never the score; inside C the joint reading decides, and f0 mixes rooted channels. W5 avoided by the direct edge; W6 by attending inside C only.

**Rests on.** N 2.3, N 11.1, N 11.3, N 12.5, N 14.2, N 14.4; D 2.8, D 2.9, D 9.4. FACTS: 30, 66, 21 % of right files have no joint change; 8.5, 45, 11 points within two hops. count first: per repository, the share of such far right files each channel puts in C.

**Refuted if.** On validation, among right files with no history and no two-hop link, the walk channels do not raise C's recall over the content channels alone; or such files rank no better after stage 1 than by f0.
