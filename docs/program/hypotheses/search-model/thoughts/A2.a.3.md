# A2 option 3: question token with relational attention bias
Lens: graph first; the graph enters the attention score, not the messages (N 12.7).

**Mechanism.** The tokens are the question Q and the candidates v_1..v_n of a retrieved set (A6; n is bounded, so W6 does not apply). Token values: Q comes from its text, diff or error text; v_i from a joint reading of v_i's content with q. Attention between any two tokens a and b:
alpha_ab = softmax_b( (W_Q t_a) . (W_K t_b) / sqrt(d) + beta(rho(a, b)) ),
where rho(a, b) is the typed relation record between the two. For (Q, v): the starting kind, and the typed paths from S(Q) to v with their decayed, size-weighted event sums. For (v_i, v_j): their typed links and joint-change sums. beta is a small learned map. After L layers, each candidate's score is read from its token. A candidate is thus described relative to the question through the Q-to-v bias, and relative to the other candidates through the v_i-to-v_j bias: a test file rises when the file it tests ranks high.
Per question: S and q are as in option 1. For task words with an empty S, the question token's bias holds only the text-match and naming fields.

**Needs from other parts.** A1: the encoders. A3: the event sums in rho. A6: the set, built at the asking time. A7: a listwise loss.

**Can.** M1 by construction, with one addition: right files that depend on each other (a source file and its test) can lift each other. M6 in part: one hop between any two tokens (N 11.3). M2 by construction inside rho, because the counts sit in the bias, not in a softmax-weighted average of values.

**Cannot.** See anything outside the retrieved set, or neighbours that are not candidates, except as compressed into rho. Counterexample: a file that matters only through an intermediate file that is not retrieved. The softmax over values normalises (N 9.5), so counts survive only as bias inputs, not as the number of tokens attended. This is near W2; it is avoided because the counts enter rho exactly. The cost is n squared per question (N 12.3).

**Rests on.** N 12.3, N 12.6, N 12.7, N 11.3, N 9.5; count first: the share of right files whose path to S runs through a file the retriever does not return.

**Refuted if.** Removing the bias between candidates, while keeping the bias from Q to each candidate, changes no per-repository validation score.
