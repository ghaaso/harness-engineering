# A6 option 2: typed restart walks from the seeds
Lens: language model first: a large pretrained model of text and code does the main work, the graph enters around or inside it. This option departs from it: reach is an exact diffusion over the repository's graph; the language model supplies content edges and reads the shortlist.

**Mechanism.** On the store cut at t, a graph over alive files with typed edges: import and use (both directions), test by import and by name, folder (via a folder node), joint change (via event nodes, weighted by A3.c.1's kernel), and content: each file to its k nearest files by frozen chunk vectors (question-free, built once per tree, updated per commit).
Seeds p0: the starting files by kind; for task words naming no file, the top BM25 matches by score. For each edge group g (code links, history, folder, content, all) and each restart rate a in a fixed bank:

pi_{g,a} = a p0 + (1 - a) pi_{g,a} P_g, by K sparse power steps, no learning (N 14.4).

A walk visits nodes in proportion to degree (D 2.8); that known bias is removed (D 2.9): x_{g,a}(f) = log pi_{g,a}(f) - log pi_g(f), pi_g the stationary visit on g. A small learned score over x, relative to the repository, and A4.c.1's path counts ranks every file. Its top N, plus named and traced files, go to the joint reader (A2.b.1). Files no walk reaches are flagged and ranked by the text score.

**Needs from other parts.** A1.b.1 (frozen chunk vectors); A3.c.1 (event weights); A4.c.1 (typed adjacency, path counts); A5.c.1 (one access path at t); A2.b.1 (shortlist scorer). A7: loss. A9: kNN cost.

**Can.** M6 by construction: no hop limit, an exact direct computation, not stacked learned steps; composition across kinds (the test of a file co-changed with an import) is one walk on "all". M2: the exact count stays a channel. M3, M4 by construction: no identities, relative features, the cut at t. M7 by construction: linear in edges per question, on a processor. M1 in part: relative to the seeds, not the question's meaning.

**Cannot.** Reach a file with no path to a seed; diffusion helps only as far as right files lie near seeds (N 14.4). Counterexample: a new feature's build setting, with no import, no similar text, no joint change. Form conjunctions (a file that matters only when two kinds reach it together): the walk is linear. Recover from a wrong seed on weak task words: it amplifies it. Nearest veto W5: reach is an exact fixed diffusion, not stacked learned steps. W11: no eigenvectors.

**Rests on.** N 2.3, N 11.1, N 14.2 (restart walks pick relevant nodes), N 14.4, N 10.5 (seeds as anchor set); D 2.8, D 2.9; record: FACTS-MODELS-SO-FAR.md (8.5, 45, 11 points of right files within two hops of imports and folders); count first: per repository, the share of right files with no joint change that some walk lifts above stationary.

**Refuted if.** On validation repositories, the walk features add no recall at N over two-hop counts and text score for right files beyond two hops; or the lift ranks track file degree alone (rank correlation near 1).
