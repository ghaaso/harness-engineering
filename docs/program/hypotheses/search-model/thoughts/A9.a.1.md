# A9 option 1: one synchronised run per design
Lens: one model trained end to end on all the cards.

**Mechanism.** *Once, on the PC, before rental:* one frozen encoder, shared by C1 and C3, embeds each chunk per content hash and each event message; each repository is packed as one graph whose edges and events carry τ_e, their main-line arrival; C3's trees and out-of-fold s_0+s_1 are fitted on processors; baselines scored.
*On the cards* each design is one data-parallel job on all three. Asking time is a mask, not a copy: V(t_q) = {e : τ_e < t_q}. Exact columns are recomputed per question from the resident graph, e.g. C_k(s,c) = Σ_{e∈V(t_q)} [s,c∈e] n_e^{-p} e^{-(t_q−τ_e)/τ_k}: storing x̃ for every file alive would take ~600 GB (10^4 files × 200 columns × 3×10^5 questions); recomputing costs ~240 sparse passes over E. Every trained part gets gradient from one loss per step (C1: stage 1, propagation, φ, adapters via L1+L2; C3: its reader).
*Sampling, known probabilities:* each card draws m ≥ 2 repositories per step with p_R ∝ W_R = Σ_q w_q, then questions with p ∝ w_q; the loss is unweighted, so the expected step is Σ w_q L_q / Σ W_R (D 3.2). Neighbours: Poisson, π_u = min(1, Hκ_u/Σκ) on the exact edge weight, sums weighted 1/π_u. Negatives: A7's π_c. Cards get repositories balanced by edge count. Draws are saved; every arm reads the same stream.
*Hours:* 0–0.5 step time and peak memory on the largest repository, epochs set from them; 0.5–3.5 C1; 3.5–6.5 C3's reader; 6.5–7.3 retrained A10 arms; 7.3–8 validation, test once, teacher scores saved. Checkpoints every 20 min. *12 GB form:* a narrower student trained on the PC by KL to saved teacher scores over U(q), same π corrections, plus the label loss.

**Needs from other parts.** C1: on-card columns, κ, L1+L2, K_J cut to 9 card-hours (about 1.5 epochs by its figures). C3: out-of-fold s_0+s_1; reader sized for 9 card-hours, not 15. A7: π_c. A10: which arms retrain; others zeroed at inference.

**Can.** M2 by construction: exact columns never sampled; neighbour sums unbiased under 1/π. M4 by construction, open on D13's cut-against-whole test on card outputs. M7 open on counts. M8 in part: one stream for arms and baselines. C1's stage 1 learns from stage 2's errors.

**Cannot.** Put trees in the joint step: C3 gains nothing from the lens. One fault stops all three cards; checkpoints bound the loss. Batches grouped by repository correlate (N 14.3); m ≥ 2 reduces it only. Nearest veto W13: holds only if measured steps match; nothing private leaves the PC; the encoder download needs the owner's word.

**Rests on.** N 14.1–14.4, N 8.4; D 3.2, D 2.9, D 9.4, D 6.4; record: FACTS-MODELS-SO-FAR.md (twice the data changed nothing). Assumption: 1.5×10^14 effective operations per card. Count first: tokens to embed (2×10^10 at 0.1 B ≈ 28 h on the PC card), largest repository's edges, questions per kind.

**Refuted if.** Joint C1 falls within the intervals of C1 with frozen out-of-fold stage 1, per unseen repository; measured steps give C1 under one epoch; cards idle over 20 % of a step; an on-card column differs from its store-cut value.
