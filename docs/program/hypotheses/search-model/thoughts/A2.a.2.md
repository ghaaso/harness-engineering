# A2 option 2: exact typed path counts as pair record
Lens: graph first; this option departs from it, following the material. The relative description is computed exactly from the neighbourhood before learning; no propagation is learned. In the record the graph part added nothing over the pair's count features, and N 13.9 calls aggregation over neighbours a learnable form of hand-made features.

**Mechanism.** At loading, for each question Q and candidate v, a pair record R(Q, v) is built from the neighbourhood cut at the asking time:
1. For every typed path p = (k, r_1, ..., r_m), m <= 2, from Q via starting kind k through relations r_i to v: the number of paths, and over paths through an event e, the sum of f(size_e) * d(age_e). The grammar (kinds times relations times direction) is enumerated in full, not picked; this answers D 9.2's "chosen arbitrarily".
2. A joint reading c(q, x_v): one encoder reads the question text and v's content as one input.
3. Flags: v named in q; v in S(Q); v a new file in a folder S touches.
Amounts are put on the repository's own scale. The question reaches the scorer only through R.
Per question: change: k = "in the change", q = the diff. Task words: k = "named in the text". When S is empty, block 1 is zeros with a flag, and c carries the score. Error: k = "in the trace", with frame depth as an extra path index.

**Needs from other parts.** A1: the joint encoder and the scale. A3: f and d. A4: the relations and directions. A6: which candidates get a record. A7 and A8: the scorer.

**Can.** M1 by construction: R depends on Q through S, the paths and c. M2 by construction: the decayed, size-weighted joint-change count is one exact entry (path: in the change, then a joint-change event). M3: no identities. M4: built from the cut store, so D13's cut-against-whole test checks it directly. A tree ranker or a small network reads it, and the baselines come from the same record.

**Cannot.** See past the grammar: a right file three import hops away gets zeros. Represent the order of events. Equal counts along every path tie: a burst last week and a year's spread with the same decayed sum cannot be told apart. The record is a projection (D 4.3, D 9.2). Nearest veto W7: not met, since the graph enters as typed path counts. W1 is avoided by the joint reading.

**Rests on.** N 9.10 (structure counted, here per pair), N 13.9, N 9.5; D 4.3, D 9.2, D 9.4, D13 (DATA-CHOICES.md); record: `research-tree/build/improve/units/T3/report.md` items 1 and 3 (the pair tree ranker leads; without the counts the graph part fell below counting); count first: the number of path types at m <= 2, and the share of right files with any non-zero path.

**Refuted if.** Option 1, on the same neighbourhoods, beats this record per repository on validation among right files that have a path of length 2 or less. That would mean what the paths leave out carries signal.
