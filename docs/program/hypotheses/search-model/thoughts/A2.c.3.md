# A2 option 3: question and candidate read jointly
Lens: exact relational computation first; this option departs from it on the text side, which the relational profile reaches only through scalars.
**Mechanism.** For each question q and each retrieved candidate c (A6), one sequence is read by a pretrained language model whose training cut-off precedes the test cut-off (D7): the question text (task words, the diff, or the error with its trace); then c's path, defined names and the parts of its content most similar to q; then a short block of exact relational facts about (q, c) in repository-relative words ("changed with 2 of the 3 starting files; last joint change 4 % of the repository's age ago; imported by a starting file"). Attention runs across question and candidate together, so every token of c is read in the light of q. The output goes to the ranker (A7) beside option 1's numbers.
**Needs from other parts.** A1 the model and whether it is tuned; A3, A4, A5 the facts in the block, cut at t_q; A6 a short candidate list; A7 how joint score and numbers combine; A9 the cost of one pass per pair.
**Can.** M1 by construction, and on the text side in its strongest form: the score is not from two vectors computed apart (W1 excluded), so "retry" in the question can meet a retry loop in c's code with no shared path word. M3 by construction: no identities, amounts in relative words. M6 in part: content read in full against the question, for what the retriever lets through. Serves the error question, where trace and code are matched line by line.
**Cannot.** Carry counts exactly: numbers in words are read approximately, so M2 depends on the numbers also reaching the ranker directly. Rank every file alive: one pass per pair, so a right file the retriever misses is lost. Read the graph beyond what the block states (N 12.6); nearest veto W7, avoided only because the block and option 1's numbers carry the graph. Leakage from pretraining is excluded only by the cut-off (D7, D12).
**Rests on.** N 9.8, N 12.5, N 12.6, N 12.7, D 6.1, D7; record: `research-tree/build/improve/units/U3/report.md` (retrievers used as two separate vectors swing by repository); `research-tree/build/improve/units/T2/report.md` (the change's text as query). count first: share of right files on the task-words and error questions sharing no identifier or path word with the question.
**Refuted if.** On unseen repositories, per repository, the joint score adds nothing over option 1's lexical and encoder columns on right files that share no word with the question.
