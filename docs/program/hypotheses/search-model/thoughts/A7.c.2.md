# A7 option 2: joint-reader residual, hard negatives, swap weights
Lens: exact relational computation first. Departs from it: the material shows text reaches an exact vector only as scalars (A1.c.1, Cannot), and 21 to 66 % of right files have no joint history (FACTS); for those a learned reader of both texts scores the pair.

**Mechanism.** Two scores.
- s1(q,c): option 1's score over every file alive, trained first, then frozen.
- Retrieved set C(q): the top K by s1, united with A6's content retrieval. Inside it, s2(q,c) = s1(q,c) + g_θ(q,c). g_θ is the head of A2.b.1's joint reader: question and candidate in one sequence, with relation tokens. Outside it, s2 = s1 - M, M above the largest g. Every file alive keeps a rank.
- *Negatives.* From C(q) \ P(q) by Poisson sampling: π_c = min(1, κ·softmax(s1/T)_c + floor). Confusable files are drawn more often, each with known π > 0; right files never.
- *Loss.* Pairs of a right file p and a sampled wrong file n:
  L(q) = (1/|P|) Σ_p Σ_n (Δ_pn/π_n) log(1 + e^{s2_n - s2_p}),
  Δ_pn the change in hits in the top ten if p and n swapped ranks under the current s2. Δ is a weight recomputed each step; no gradient passes through the sort.
- Right files outside C(q) are added in training and marked. Their share is reported.
- *Weights* as option 1: equal per repository, a bound β per example, pull-request steps as one question, bulk apart; set on validation.

**Needs from other parts.** A2.b.1: joint reading, with its linear path for exact amounts. A1.b.1: the tuned reader and its soft tokens. A4.b.1 or A4.c.1: relation statements or counts. A5.b.1: the reader's cut-off mark. A3.c.1: exact amounts in s1. A6: the content retrieval. A8: whether s1 and g are separate models.

**Can.** M1 by construction: question and candidate are read jointly (N 9.4, N 9.8). M6 in part: a far file with no link, inside C(q), is scored by its content. M2 by construction, through the s1 offset, since a reader counts badly (N 13.9). M7 open on a count of pairs per hour on three cards. M8: g = 0 is option 1.

**Cannot.**
- Rank a right file that stage one leaves out of C(q). K bounds what it finds.
- Avoid more label noise. Counterexample: a module's unchanged copy elsewhere sits at the top of s1 and is drawn with high π. Nearest W9; not under it, because labels are D8's.
- Give a loss whose expectation is a known total. The swap weight is computed on the sample, and the loss is conditional on C(q).
- Escape the reader's memory of public repositories (A5.b.1). W6 is not met: attention spans one pair.

**Rests on.** N 9.4, N 9.8, N 12.7, N 13.6, N 13.9, D 3.2, D 6.2. Record: `research-tree/build/improve/units/T3/report.md` item 1 (text added 0.010; the change's text names a right file in 37 % of tasks). Count first: the share of right files in C(q) at K, by repository; tokens per pair.

**Refuted if.** Per validation repository, g adds nothing over s1 among right files in C(q) with no history. Or uniform negatives from C(q) without Δ score the same.
