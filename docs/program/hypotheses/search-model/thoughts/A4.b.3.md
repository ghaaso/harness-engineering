# A4 option 3: link kinds as attention bias inside the model
Lens: language model first.

**Mechanism.** The pretrained model reads one sequence: the question segment, then one segment for each file of a
retrieved set (the starting files and the candidates, each a path and a content summary). The graph enters the
attention itself. For tokens i in segment u and j in segment v, every head h adds a bias:
s_ij = q_i·k_j/sqrt(d) + sum_{r in links(u->v)} beta_{h,r,dir} + gamma_h·log(1 + a_uv).
dir records whether u is the link's source or its target, so u attending to v differs from v attending to u. For a pair
with no link, the bias is that of the shortest typed path between them (its first kind and its length). Parameters:
heads × kinds × 2 + heads. The score of each candidate is read from its own segment.

**Needs from other parts.** A6: the retrieved set; its size is bounded by the context. A3: the amount a_uv. A1: the
encoder and the content summaries. A7: the loss across segments.

**Can.** M5 by construction: kinds and direction are separate numbers in every head, and parameters grow by 2 × heads
per kind. M1 by construction: candidates attend to the question and to each other, so the same surroundings read
differently under different questions. Candidates are scored jointly, so one file can explain another. N 13.8 patterns:
asymmetry by construction (dir), composition in part (layers chain links inside the set), one-to-many (no entity
vectors). M3: only biases and model weights are learned.

**Cannot.** Pass counts exactly. The softmax normalises, so log(1 + a) acts only relative to the other links in the
row. Counterexample: one partner changed together 3 times among neighbours changed 1 time looks the same as 30 among
10. W2 is nearest; it does not apply only if A3 passes the count through another channel, which is stated here as a
need. It cannot see files outside the set (W6 is avoided only because the set is retrieved; reach is A6's part). The
bias set by the shortest path drops all but one path. Counterexample: a candidate reached by twenty two-link paths
gets the same bias as one reached by one.

**Rests on.** N 12.7 (edge features and shortest paths go into the attention score), N 12.6 (attention is message
passing; without a bias it would lose adjacency, W7), N 12.3 (dense attention over a small set), N 9.5 (why softmax loses
counts), N 13.4 (weights split by kind). Count first: the size of a retrieved set that fits the context with useful
summaries.

**Refuted if.** Setting every beta to zero at validation leaves the scores unchanged. Or giving beta_fwd = beta_inv the
same value changes nothing.
