# A10 option 1: two ladders, one floor, one bridge
Lens: a ladder: each arm removes one decision of the fullest design.

**Mechanism.** C1 and C3 are the two tops. Each has a ladder down to a shared floor, and all arms are scored on the same questions. An arm keeps everything upstream of its removed decision frozen from its top and retrains only what lies downstream.
- Floor (untrained, D12): b_k; counting with 1/n; recently changed; folder; imports; BM25; named files; trace files; frozen cosine.
- Stage 1: L is C1's linear stage over x̃, T_x is trees over x̃, and T is C3's trees over R_ex. T is also run without one block at a time: path types, event kinds, H, reach and echo, per-kind trees. L is also run with raw logs in place of quantiles.
- Stage 2: each rung is trained on the same quarter of the training clusters as its reference (known π, D 3.2). C1-ref keeps J frozen and drops one of: a_k, U x̃, the gate, types (merged, one-hot kind), J. C3-ref drops R_ex from the head; the gate is tested by retraining the head alone.
- Bridge: C1's stage 2 on C3's out-of-fold offset and shortlist, against C3-ref. The one decision between them is propagation or the reader (CRITERIA §4).
- Card-hours, of 24: the tops 5.5 each; six C1 rungs 0.75 each; two C3 rungs 1.5 each; the bridge 0.75; one double removal (U x̃ with the gate) 0.75; scoring 3.
- Reading: each arm is paired with the rung above it per repository, then averaged with 1/π weights and cluster-resampled intervals (D12). A decision holds if its removal costs more than the interval in a segment named before the run. The segments: rank correlation between questions asked at the same moment (a_k); no joint history and no code link (J, reader); the right file's link kind (types); trace depth with the message (R_ex); no two-hop path (reach); extreme sizes (raw logs). A failed decision leaves the 12 GB form.

**Needs from other parts.** From C1: stage 2 takes an outside offset and shortlist; J can be frozen. From C3: the out-of-fold offsets are saved; the head can be split from the body. From A9: vectors precomputed, trees run beside the cards, the quarter sample.

**Can.** M8 by construction: one decision per rung, the baselines on the same examples, the designs' own Refuted-if lines as predictions, segments. M7 open on the counts below.

**Cannot.** It cannot see redundancy. When two decisions carry one signal, removing either loses nothing. The double removal tests only one pair. Frozen upstream parts were co-adapted with the decision that is removed. A gain that shows only at full scale stays hidden. Comparing the two tops compares bundles. Error segments may be too small. Nearest veto: W12; every rung is a named decision, not a sweep.

**Rests on.** N 1.1; D 3.2, D 7.3; DATA-CHOICES D12; record: FACTS-MODELS-SO-FAR.md (count features alone matched the whole). count first: card-hours per quarter epoch; validation questions per segment.

**Refuted if.** The double removal loses beyond the interval while each single removal does not; or a quarter reference differs from its top in the named segments.
