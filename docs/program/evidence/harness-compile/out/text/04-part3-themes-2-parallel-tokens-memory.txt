Planning parallel work
10 in use · 0 tested · 0 built · 12 designed · 0 ideas · 0 parked Work packages: WP3WP4WP12
More lanes help only until the first limit is reached, the knee. Past it they add queues, tokens and collisions. In the testbed, ten lanes run at once hit the usage limit within about 15 minutes M, while two at a time got further.
The ideas here decide before a wave starts which slices can run side by side, how many lanes are worth it and where they would collide. Since 13 November FixFlow’s ship plan runs a coordinator session with one lane session per phase, so this theme is moving from design into daily use.

Spend fewer tokens per result
7 in use · 6 tested · 4 built · 8 designed · 11 ideas · 8 parked Work packages: WP5WP6aWP12
We counted every model call on this PC for both projects: 35,834 calls and 7.35 billion context tokens M. 97 % of those tokens were re-reads of a window the model had already read M, so the number of calls times the size of the window is what we have to manage.
The ideas here are the four levers the token report found, the governor and the written budget of harness v2, and smaller habits that keep windows short. Each lever is sized as an exposure, the share of tokens it could touch, which tells us where to aim; the savings themselves are what the next measurements will show.

Remember what we learned
5 in use · 3 tested · 8 built · 35 designed · 17 ideas · 3 parked Work packages: WP6aWP6bWP6cWP7WP8
Every new session starts without what the last one learned, unless something carries it across. The ideas here give the harness a memory: the knowledge store designed in PR #183, the reasoning-cache library of harness v2, and smaller habits such as turning a lesson into a check.
My goal for the library is that a cheaper model finishes more of our work at the same quality. The pathway map shows, step by step, where an entry can be lost before it helps, which tells us what to build first. Both designs are complete on paper and unproven so far; their first steps are cheap tests built to prove them.
Start with 100 pieces of work the cheap model would get wrong on its own. Each bar is how many are still on track after that step.
