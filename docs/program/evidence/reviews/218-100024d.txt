- Order of events: a technician's completion and resubmits do not restart the cap (C13 test); a manager's resubmit before the send restarts it (new test); a send or negotiate by anyone does not; an override restarts it, and a later correction by a manager restarts it again; when a manager writes the first completion, the reference is the first original ever.
