Restore gate, run in its own image (mawk, `--network none`):
- Refused: quoted keys, `export` followed by a tab, a trailing comment, CRLF with a spaced colon, a BOM before an indented key, a bare name.
- Let through, and safe:
  - `EXPORT fixflow_environment=dev`: Compose itself rejects that file ("key cannot contain a space").
  - A duplicate exact `FIXFLOW_ENVIRONMENT=dev` later in the file: the rendered config still shows `production`.
  - A multi-line quoted value hiding a key: Compose treats it as part of value `X`.

Loader, settled by running pydantic-settings against both orders of the duplicated variable: whichever spelling comes last in the environment wins (`FIXFLOW_` first gave `dev`; lowercase first gave `production`). The smoke's own probe shows that with the gate skipped, `environment=dev` wins. So the gate is required, and it holds.
