What this page answers, and what it does not

It answers two questions. Do three storage engines differ: SQLite (relational), LadybugDB (graph) and the DuckDB graph layer, holding the same facts? Does a parser-built code graph beat a scripted search at finding the other code that a real change touched? It does not test a layer of meaning that a model reads from documents (what graphify adds), facts with time validity, cached conclusions with invalidation, orientation (summaries and maps), an agent actually using any of these tools, or the tokens a working session spends.
