phase('Engine')
const engine = await agent(`${COMMON}

YOUR JOB: BUILD THE GRAPH DESCRIPTION, THE ENGINE AND ITS TESTS.

1. ${OUTDIR}/map.json. One declarative description of the model in the brief, which both the engine and (later) a page will read. It holds: the parameter ids, each with a plain-language meaning under 25 words and its group; the four episode attributes and how a class's chance is formed; the three policies; the states (id, a label of at most six words, the step it belongs to, whether it is an outcome); the branches (from, to, a chance expression, a cost expression, the tier the cost is paid at, the number of calls, a label of at most eight words, and an empty list for limitation ids to be filled in later); the outcomes; and the stock equations of the brief's section 8. Expressions are strings over parameter ids, class attributes and named derived values (for example the gate's catch chance g). Carry the kind of entry in hand (none, good exact, good similar, composite full, composite part, wrong accepted) in the states, so that every branch chance is a plain expression.

2. ${OUTDIR}/engine.js. Pure functions, no dependencies, usable from node (module.exports) and from a browser page when inlined (a global named PathwayEngine). It must compute everything in the brief's section 9: outcomes and cost per class and overall for a policy; cost by tier and call counts; every route with its chance and cost (bounded loops), sortable; the time path of section 8; the headline ratios; the ensemble with a seeded random generator, percentiles, the share of draws where the library policy is cheaper than top_first with a wrong rate no higher, the Spearman ranking and the one-at-a-time swings; and a conservation check. Evaluate expressions against a whitelisted scope only.

3. ${EVDIR}/params-placeholder.json. A middle value, a low and a high for every parameter so the engine can run. Mark the file clearly as placeholders that carry no evidence. A later agent writes the real table.

4. ${EVDIR}/engine-test.js.txt. Tests, runnable with: cd ${EVDIR} && node - < engine-test.js.txt. At least: branch chances out of every state sum to 1 and outcome chances sum to 1 for every class under 500 random parameter draws; three cases worked by hand in comments, with the engine matching to six decimal places; with both trigger rates at zero the library policy matches cheap_ladder in outcomes; with every catch and success rate at 1 nothing escapes; raising a pure cost parameter never changes an outcome chance; the time path starts from an empty stock.

Run the tests and fix until they pass. Where the brief is ambiguous, take the reading closest to its text and list it under deviations_from_brief. Do not change the model.

Return the list of files, a description of the engine's functions and their inputs and outputs (under 250 words), the counts, the hand checks, and any deviation.`, { label: 'engine', phase: 'Engine', schema: ENGINE_SCHEMA, model: 'opus', effort: 'high', agentType: 'general-purpose' })
