# w1 step 1b: second attempt (sonnet, collect) for papers a collector could not open

Read first: `R:w1-brief-common.md`; `R:w1-brief-collect.md` (the reading recipe and the block format). Your launch
names one collect file and the papers to retry; read in that file only the block and the "Not opened" row of each.

For each named paper make one real attempt by public routes, in this order, and stop at the first `%PDF-` copy:
the publisher's open archive (ACM, VLDB, USENIX open pages); the author's home or group page; a university
repository (DSpace, eScholarship, a thesis repository); arXiv; a technical-report copy; a course page. Search the
web for the paper's title in quotes with "pdf". Try a host the first collector did not try. A copy that is a sign-in
page or a bot check stays closed: do not work round it, list it "needs the owner's sign-in". No pirate copies.

Append to the same collect file, at its end, a section `## Second attempt (2026-11-19)`: per paper, the URLs tried
with what each returned, and, if opened, a full block in the format of `R:w1-brief-collect.md` step 4 with quotes
cited `R:papers/w1/<short-name>/paper.txt:<line>`. Change nothing above that section.

Done returns (at most six lines): per paper `opened` / `still closed (reason)`; one line per new figure that bears
on the lane's frame.
