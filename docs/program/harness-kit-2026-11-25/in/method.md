# The method for running helpers: what the records say (collected 2026-11-25)

Collected for the writer of the orchestration guide. Nothing is judged here: each row says what a record says and how far it is known.
Statuses: `measured here` (a number from a run in this project), `observed here` (seen working or failing, no number), `quoted` (paper or documentation), `hypothesis` (reasoned or designed, never run), `failed or changed` (run, did not hold; the replacement is named), `not found` (looked, no record).
Paths are from the repository root. `INDEX` = `library/INDEX.md`. `ORCH` = `research-tree/ORCHESTRATION.md`. `ENF` = `research-tree/build/ENFORCEMENT-TABLE.md`. `DESIGN` = `docs/ORCHESTRATION-DESIGN-2026-10.md`. `STATUS` = `docs/program/evidence/harness-method-status-2026-11-18/README.md`. Records are found with `bash library/lookup.sh -f <id>`.
Limits of this reading: records were read through the lookup and the files named in the brief; the 3,408 extractor records and the papers behind quoted rows were not opened. Figures come from one repository on one PC in one week unless a row says more.
