# Results: what this project measured about running work side by side, time, and where tokens go

Collected 2026-11-25 by a Sonnet reader for the kit's writer. Nothing is judged anew. Numbers are copied as the record
gives them, with the record's own caveat. "Record" means an id in `library/` (read with `bash library/lookup.sh -f <id>`;
`hc1-` records are in `library/journal/2026-11-19/hc1.jsonl`, `t7-` in `library/journal/2026-11-23/t7.jsonl`).
Seven measures: throughput, efficiency, token count, token cost, time taken, quality, hallucinations. Tokens are counted
as the record says (usually input + cache creation + cache read + output, once per message id, so cache reads dominate).
Almost every row is one trial, one repository and one PC (Windows 11, 12 cores, 31 GB); see "Not measured" at the end.
