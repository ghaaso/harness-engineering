Method and checks

Source. Claude Code writes one JSONL transcript per session plus one per subagent. Each assistant message carries the API usage of that call. Streamed responses repeat the same message id with the same (or partial) usage, so each id is counted once at its maximum. Synthetic messages are skipped.

Independent re-measurement. A second agent, given only the format facts, re-measured both repos with its own script: calls, context and output agreed within 0.3 percent, by-model and by-role splits within rounding.

Harness cost-state. The harness's own running totals cover less than the transcripts; they are reported as a lower bound.

What the shares are. Context tokens are what the model read on each call, so a token that stays in a window is counted on every later call. Output tokens include thinking. Tool output is measured once, in characters, at the moment it arrived.

Classification. Sessions were classified by an inventory agent from the title and first prompt; several sessions in the Clinic repo's folder did FixFlow design work and several in the FixFlow folders did harness work, so "kind of work" is by content, not by folder. Unrelated personal sessions that happened to use a repo folder as their working directory are kept in the totals and shown as "unrelated".
