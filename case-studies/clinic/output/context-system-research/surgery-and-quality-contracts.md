# Shipped context surgery and quality contracts

Read-only source audit, 2026-10-09. No candidate was installed, no settings were changed, and no live model benchmark was run. Scope: retain useful information from an approximately 800k-token Claude Code Opus 5.5/Ultracode workflow in roughly 300–400k active tokens, with automatic retention and recovery. Corpus-map is only the workload; clinic sources and contracts were not read.

## Decision

Distil is a real shipped compressor with automatic operation, exact-output recovery and quality monitoring. Its current evidence does **not** establish the requested information equivalence or absence of added work. Jev's native tool clearing can remove stale outputs continuously while preserving other conversation content; its quality gate deliberately keeps outputs for information-heavy tasks, and it is not lossless virtualization. Scalpel stores exact originals and persistently reapplies history surgery, but its beta has concrete compatibility gaps for current Claude request paths and preserved thinking. None of these is established as the primary 800k → 350k solution.

## Distil

**Pins and delivery.** Latest inspected main: [`d55b7ef`](https://github.com/dshakes/distil/tree/d55b7ef16a5accaf41489d9181baf3c4cdd87763). Published `distil-llm==1.57.0` was uploaded on 2026-10-05 and requires Python ≥3.9. The annotated `v1.57.0` tag object is `45d76be…`; its actual release commit is [`440a701`](https://github.com/dshakes/distil/tree/440a7019fe88fe075971fba8f7b615ea4cf87216). PyPI wheel SHA-256: `d45a78999204ef72f22c9f6e22dc4d6c33cca5e34fb5594ea59e2a3663318e99`. [Published metadata](https://pypi.org/pypi/distil-llm/1.57.0/json).

**Automatic mechanism and fidelity.** The release contains a native Claude Code `PostToolUse` hook. It replaces a new output before it enters history, using documented `updatedToolOutput`, rather than rewriting earlier turns. Tier 0 performs reversible/minimal transformations such as JSON minification. Tier 1 produces a digest only after storing and reading back the original byte-exact; the agent can recover it with `distil expand <handle>` or an optional `distil_expand` MCP tool. Unknown schemas, errors and transformations that enlarge the result pass through. Native file reads and shell whole-file reads are protected for exact editing. This is lossless **storage**, while digest reasoning still requires the agent to recognize and retrieve missing details. [Shipped hook](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/hook.py), [Claude hook contract](https://code.claude.com/docs/en/hooks).

Subscription/OAuth login defaults to Tier 0; digest is an explicit opt-in. The wrapper uses a loopback proxy and process-scoped `ANTHROPIC_BASE_URL`, preserves authentication, and keeps Claude MCP tool search enabled. No Opus 5.5/Ultracode outcome benchmark was found. Read-heavy input, startup instructions and complete project knowledge therefore do not automatically become a smaller equivalent working set. [Billing policy](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/policy.py), [wrapper](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/proxy.py), [Claude preset](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/onboard.py).

The proxy also implements cold-point eviction: after a known cache TTL has expired, older tool outputs can become recovery stubs, then remain stable on later requests. Its persisted eviction set covers worker restarts within the same wrap session; a fresh wrap or resumed conversation in another terminal has a new lineage. The design document still labels GA as gated on soak/live A/B. Cache expiry alone does not waive current preserved-thinking prefix rules; the native append-only hook avoids this particular earlier-history edit. [Cold-point contract](https://github.com/dshakes/distil/blob/d55b7ef16a5accaf41489d9181baf3c4cdd87763/docs/adr/0014-cold-point-recompression.md), [Anthropic preserved thinking](https://platform.claude.com/docs/en/build-with-claude/preserved-thinking).

**Quality is measured, not guaranteed.** Its September digest sample agreed on the next decision 102/206 times, versus original-context self-agreement 113/206: a 5.3-percentage-point deficit. The implemented per-mode guard can hold digest at lossless-only when the recent upper confidence bound exceeds its 5-point budget. State is persisted locally. Release CLI defaults to shadowing 2% of requests, adding uncompressed model calls; it also has a local fact-retention meter. Per-step agreement is explicitly insufficient to certify end-to-end task success, and the trajectory certificate requires supplied matched outcomes. `distil prune` is a replay/evaluation command, not evidence that all production requests receive causal pruning. [Per-mode guard](https://github.com/dshakes/distil/blob/d55b7ef16a5accaf41489d9181baf3c4cdd87763/docs/adr/0022-per-mode-certification-hold.md), [shipped CLI](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/cli.py).

**Most relevant outcome evidence is negative/inconclusive.** The author's seven-task SWE-bench Verified hard-task pilot used Sonnet 5.5 at effort `max`, approximately 50–100 steps per task. Plain and Distil each solved 6/7; this was below the harness's 100-pair verdict floor. The headline cost ratio was 0.84, with CI [0.39, 1.24], driven by one early `max_tokens` failure rather than demonstrated compression savings. On the other six tasks, Distil cost $17.79 versus $16.21 (**9.7% more**), took median 75 versus 59.5 steps, and made 37 expansion calls. Prompt size per step was only about 4.5% smaller. The author reports no demonstrated long-horizon saving. This is not evidence of equivalent information from 800k in 350k. [Pinned pilot](https://github.com/dshakes/distil/blob/d55b7ef16a5accaf41489d9181baf3c4cdd87763/benchmarks/results/swebench-verified-hard-max/README.md).

**Concrete bounded setup, if later selected:** install the pinned Python package, then `distil hook install --client claude` for automatic Tier 0, or add `--digest` for recoverable digests on subscription login. `distil hook --selftest`, `distil hook status` and `distil hook --stats` expose schema checks and receipts; `distil hook uninstall --client claude` removes its own entry. The proxy alternative is `distil wrap --expand -- claude <existing model/effort arguments>`. These are documented available actions, not actions performed in this audit. [Release CLI](https://github.com/dshakes/distil/blob/440a7019fe88fe075971fba8f7b615ea4cf87216/distil/cli.py).

## Jev routing: native tool clearing

Pinned [`7e18fa4`](https://github.com/nekowasabi/jev-routing/tree/7e18fa4af867217bcc422676c79dd1710da2f1ce), repository archived 2026-09-26. Its proxy appends Anthropic `clear_tool_uses_20250919`, default trigger 100k input tokens, clear-at-least 40k, keep three tool uses. Claude subscription login is supported by launching the existing client through the proxy. The API edits the server-visible prompt while the client retains full history. Other user/assistant state is retained; cleared tool results have no shipped exact-output expansion tool. [Native edit implementation](https://github.com/nekowasabi/jev-routing/blob/7e18fa4af867217bcc422676c79dd1710da2f1ce/internal/proxy/context_edit.go), [Claude launcher](https://github.com/nekowasabi/jev-routing/blob/7e18fa4af867217bcc422676c79dd1710da2f1ce/internal/host/host.go), [official server-side semantics](https://platform.claude.com/docs/en/build-with-claude/context-editing).

Its live measurements found that the server recomputes clearing from full history on each request and stops at the requested clearing amount: removal is not cumulative and the remaining active context can keep growing. Optional Jev gating classifies a conversation once, with a blocking remote call and a 20-second timeout. It allows stale-output clearing for stepwise fixes but keeps outputs for surveys/audits. Gate decisions and telemetry are in memory and disappear on restart. [Gate](https://github.com/nekowasabi/jev-routing/blob/7e18fa4af867217bcc422676c79dd1710da2f1ce/internal/proxy/clear_gate.go), [live measurements](https://github.com/nekowasabi/jev-routing/blob/7e18fa4af867217bcc422676c79dd1710da2f1ce/docs/MEMO.md).

Six paired Sonnet 5 medium-effort bug-fix runs preserved reported quality and showed median 11.1% same-path token savings; six survey runs avoided clearing. Ungated survey clearing caused substantial rereading, up to 699,727 rework tokens. The authors did not live-verify the default 100k/40k configuration. This supports a stale-output adjunct with a fidelity gate, not 800k useful-information retention in 350k. [Pinned measurements](https://github.com/nekowasabi/jev-routing/blob/7e18fa4af867217bcc422676c79dd1710da2f1ce/docs/MEMO.md).

## Scalpel: recoverable history surgery

Pinned [`a2e4eeb`](https://github.com/MohammedBasioni/scalpel/tree/a2e4eebda757bd1149ac161d57daf62ff28456b8); published `ctx-scalpel@0.1.0` beta, Node ≥20. It continuously identifies old duplicate, superseded, stale or dead-UI tool results, protects the newest ten messages, and replaces selected results with local-file recovery stubs. Original bytes, surgery logs and session metadata persist under `~/.scalpel`; committed cuts are reapplied to subsequent requests and after restart. User/assistant prose and tool inputs remain. [Ledger](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/ledger.ts), [spill](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/surgeon/spill.ts), [pipeline](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/pipeline.ts).

Two source-level limitations matter now. The published proxy only intercepts an exact `/v1/messages` URL, so queried routes such as the official SDK's `/v1/messages?beta=true` pass through. It also rewrites earlier tool results while retaining later signed thinking, without current prefix-binding handling; Anthropic documents that such client-side edits can invalidate all subsequent thinking on Opus 5.5. Actual current Claude Code request routing was not captured, so the first issue is conditional. The second requires a compatibility fix or demonstrated supported path. [Proxy](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/proxy.ts), [SDK route](https://github.com/anthropics/anthropic-sdk-typescript/blob/main/src/resources/beta/messages/messages.ts), [current thinking contract](https://platform.claude.com/docs/en/build-with-claude/preserved-thinking).

Its advertised 19.3% weighted savings are simulated cache-cost replay over 131 historical sessions, not model reruns, task-outcome preservation or latency measurements. Exact originals are recoverable, but a later partial file read can mark an earlier whole-file result as superseded, and recovery itself adds work. It is a useful implementation reference; the shipped beta is not a justified recommendation for this workload. [Replay benchmark](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/bench.ts), [selection rules](https://github.com/MohammedBasioni/scalpel/blob/a2e4eebda757bd1149ac161d57daf62ff28456b8/src/ledger.ts).

## Dasein benchmark: outcome evidence at a smaller scale

Pinned [`466077f`](https://github.com/daseinlabs/code-compression-bench/tree/466077f002e6ef71fe5e8f24fc1c930edd4e3691). The primary benchmark uses headless Claude Code, Sonnet 4.6, 100 SWE-bench Verified tasks and the official Docker grader. Parsec solved 62/100 versus baseline 57/100; total cost fell 39%, input tokens 54%, wall time 25%, and mean peak context was approximately 41.4k versus 79.8k. Caveman solved 58 and cost 19% less; RTK solved 54 and cost 13% more; Headroom solved 58 and cost 44% more. Thus token reductions alone do not establish lower cost or equivalent outcomes. The baseline context scale is about 80k, not 800k. Dasein owns Parsec and sponsors/operates this benchmark; the official third-party grader supplies the task outcome test. No Opus 5.5/Ultracode trial is reported. It does not establish the requested fidelity contract. [Primary pinned results and method](https://github.com/daseinlabs/code-compression-bench/blob/466077f002e6ef71fe5e8f24fc1c930edd4e3691/README.md).

**Parsec is deployable, with a scoring dependency.** Its public repository is [`daseinlabs/parsec`](https://github.com/daseinlabs/parsec/tree/e97063caac17067e1da876f80d8ee15c41060b18); inspected main is `e97063c…`, and published Windows-capable `v0.2.20` is pinned at [`57d14b8`](https://github.com/daseinlabs/parsec/releases/tag/v0.2.20). The Claude marketplace plugin invokes setup, writes `ANTHROPIC_BASE_URL` to a local proxy and starts it; existing Claude credentials are forwarded directly to Anthropic. Per-request curation scores chunks, preserves the current output in full, then folds older outputs into selected byte-exact chunks and omission markers. Recovery repeats the identical original tool call rather than reading an exact-original archive. [Shipped setup](https://github.com/daseinlabs/parsec/blob/57d14b82aa85dc7988f912bb74064e6d1614dd45/packages/plugin/skills/setup/SKILL.md), [freezer/recovery](https://github.com/daseinlabs/parsec/blob/57d14b82aa85dc7988f912bb74064e6d1614dd45/packages/engine/src/freeze.rs).

Curation needs a scoring service: by default chunk text, capped at 2,000 characters per chunk, goes to the hosted service. A Python GNN/bge-large service and published curator checkpoint can instead be self-hosted. The release requires either a Parsec account key or self-host `PARSEC_BRAIN_KEY`; without either, hooks and proxy save nothing. Scoring adds a cacheable network call per turn with a default 10-second timeout and fail-open behavior. This is a shipped automatic learned-pruning candidate with stronger task-outcome evidence than the other systems in this note, but neither historical-output recovery nor the requested large-context fidelity/latency guarantee follows from that evidence. [Release disclosure/self-hosting](https://github.com/daseinlabs/parsec/blob/57d14b82aa85dc7988f912bb74064e6d1614dd45/README.md), [key gate](https://github.com/daseinlabs/parsec/blob/57d14b82aa85dc7988f912bb74064e6d1614dd45/packages/proxy/src/apikey.rs), [scoring configuration](https://github.com/daseinlabs/parsec/blob/57d14b82aa85dc7988f912bb74064e6d1614dd45/packages/proxy/src/brain.rs).
