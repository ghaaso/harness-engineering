## Acquisition and applicability notes

- Official Codex URLs redirected from `developers.openai.com/codex/` to `learn.chatgpt.com/docs/`; citations use the current fetched destinations.
- Direct Markdown pages were advertised but the web reader rejected their content type. HTML pages and targeted sections were used instead.
- The ACM Queue DevEx page could not be fetched. The author's hosted paper and author-organization landing page supplied primary evidence; no secondary summary was substituted for paper content.
- One Phoenix overview URL was inaccessible; its current tracing tutorial supplied the scoped claims. No unseen dataset documentation is claimed inspected.
- OTel's former GenAI convention pages are explicitly no longer maintained there. The destination README was fetched, but an attempted guessed raw span-file URL failed. No concrete span mapping is claimed verified.
- A guessed administrative cost URL returned 404. Pricing was not used to calculate spend; no per-task dollar price is asserted. Optional estimate fields were inspected in the **locally generated** protocol schema, with live availability still unknown.
- Search results included secondary commentary and community anecdotes. Those are not evidence for the technical conclusions here.
- The earlier local ACE source review distinguishes the HumanLayer context-engineering repository from other research named ACE. This investigation does not merge those projects or import unrelated paper effect sizes.
